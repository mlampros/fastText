# Print Usage Information when the command equals to 'print-word-vectors'

Print Usage Information when the command equals to 'print-word-vectors'

## Usage

``` r
printPrintWordVectorsUsage(verbose = TRUE)
```

## Arguments

- verbose:

  if TRUE then information will be printed in the console

## Value

It does not return a value but only prints the available parameters of
the 'printPrintWordVectorsUsage' function in the R session

## Examples

``` r
library(fastText)

printPrintWordVectorsUsage()
#> usage: fasttext print-word-vectors <model>
#> 
#>   <model>      model filename
#> 
```
