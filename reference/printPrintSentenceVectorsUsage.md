# Print Usage Information when the command equals to 'print-sentence-vectors'

Print Usage Information when the command equals to
'print-sentence-vectors'

## Usage

``` r
printPrintSentenceVectorsUsage(verbose = TRUE)
```

## Arguments

- verbose:

  if TRUE then information will be printed in the console

## Value

It does not return a value but only prints the available parameters of
the 'printPrintSentenceVectorsUsage' function in the R session

## Examples

``` r
library(fastText)

printPrintSentenceVectorsUsage()
#> usage: fasttext print-sentence-vectors <model>
#> 
#>   <model>      model filename
#> 
```
